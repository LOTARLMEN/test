### Моей задачей было разработать приложение предоставляющее `REST API` для работы с кошельками пользователей.
___
### Обязательные условия:
1. **Кодовая база**:
   - Код должен соответствовать стандарту **PEP8**.
   - Необходимы миграции для базы данных.
   - Использовать асинхронный веб-фреймворк (к примеру _FastAPI_)
2. **Конкурентность**:
   - Уделите внимание корректной работе приложения в конкурентной среде: 
     - параллельные запросы, включая запросы на изменение баланса одного и того же кошелька, должны обрабатываться корректно.
3. **Инфраструктура**:
   - Приложение должно запускаться в Docker-контейнере.
   - База данных — также в контейнере.
   - Вся система поднимается одной командой через docker-compose.
4. **Тестирование**:
   - Эндпоинты должны быть покрыты тестами.
5. **Итог**.
   - Готовое решение необходимо разместить на GitHub и предоставить ссылку.
